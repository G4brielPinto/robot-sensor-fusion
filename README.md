# Robot Sensor Fusion with EKF and UKF

A Python simulation that compares Extended Kalman Filter (EKF) and Unscented Kalman Filter (UKF)
state estimation for a robot with speed, gyroscope and GNSS-style observations.

## Scope

The notebook defines a nonlinear robot motion model, simulates noisy observations and evaluates
both filters against the simulated ground-truth trajectory. It reports trajectory error using RMSE,
MAE and R-squared measures.

No external dataset is required: sensor values are generated by the simulation.

## Setup

Use Python 3.10 or newer in an isolated virtual environment.

~~~bash
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
jupyter lab
~~~

Start Jupyter from the repository root, then open notebooks/robot_sensor_fusion.ipynb.

## Reproducibility notes

- The notebook runs a simulated robot trajectory, not a real vehicle or production sensor feed.
- EKF and UKF settings can be changed in the parameter-configuration section.
- Historical conclusions embedded in the notebook are from the original academic run; execution
  outputs and execution counts were removed before this portfolio edition was prepared.
- Re-run the notebook to generate fresh figures and metrics.

## Privacy and sharing
